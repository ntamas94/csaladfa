# Ricz–Kádas családfa

Családfakutatás: a Ricz, a Kádas és a Gubincsik ág, kiegészítve az óbecsei (ma Bečej, Szerbia) anyakönyvi és közjegyzői forrásokkal.

- **`index.html`**: a családfa ábrája, a talált iratok és a nyitott kérdések. Böngészőben megnyitva működik.
- **`atiratok.md`**: a forrásokból készült átírások.
